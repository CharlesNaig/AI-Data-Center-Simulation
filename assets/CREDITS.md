The files are bundled as artwork used by this educational model, not as a standalone icon pack. Keep the Icons8 credit/link in the model Info tab and README when sharing. [Icons8 attribution guidance](https://icons8.com/license) supports credits in desktop About sections and academic references/captions. The model Info tab supplies that credit; the interface also names Icons8.

All resource calculations are independent of these images. There are no decorative turtles. The river, roads, land colors and labels are native NetLogo drawing/patch content.
