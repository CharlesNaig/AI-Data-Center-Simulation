# Revert to the original V2 layout

This is the complete pre-change snapshot saved before the natural tree/house arrangement on 2026-10-13. It includes the original model, assets, tests, README, verification evidence and screenshots. `manifest.json` records SHA-256 hashes; `scenarios-before.csv` preserves the original monthly results for comparison.

Close the V2 model in NetLogo, then run this from the STS root:

```powershell
rtk proxy powershell -NoProfile -ExecutionPolicy Bypass -File "v2/backups/2026-10-13-before-natural-layout/Restore.ps1"
```

The script verifies the backup, saves the replaced version under a new `v2/backups/before-restore-*` folder, restores only the listed V2 files, and checks every restored hash. It does not delete files or touch V1, Git, the approved plan or Obsidian. Reopen `v2/models/ai-data-center-community-v2.nlogox` after restoring. Any generated full traces in `v2/results/` can be regenerated by the restored verifier.

For a preview without reverting, open `snapshot/models/ai-data-center-community-v2.nlogox` directly; its model-relative PNG assets are included.
